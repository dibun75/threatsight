## Limitations recorded for ThreatSight

- EU directive text does not automatically bind a Norwegian entity without national implementation confirmation.
- Norwegian transposition status and sectoral scope can change; the profile must show review date and uncertainty when undetermined.
- Deadlines in ThreatSight are **operator-confirmed configuration**, never inferred solely from media or CVSS.
- Default fields: `legal_applicability=not_determined`, `reporting_obligation=not_determined`.
- Legal/regulatory liaison confirmation is required before any draft regulator-notification preparation note is marked approved.
- ThreatSight never sends notifications and never claims NIS2 compliance.
