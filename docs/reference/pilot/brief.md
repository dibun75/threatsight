# ThreatSight — one-page brief

ThreatSight helps security and engineering leaders see which **public threat and exploitation signals** matter for **their named business services**, then drive **accountable readiness actions** with **verifiable evidence**.

## What it does

- Collects public intelligence (e.g. Radar / exploitation sources) separately from customer telemetry
- Correlates signals to a workspace inventory of services and technologies
- Distinguishes authoritative vs researcher-observed evidence
- Assigns readiness actions with human approval — no autonomous remediation
- Produces evidence manifests and optional cryptographic signatures
- Supports a response/crisis exercise workspace for practice — not live incident command

## What it is not

Not a SIEM replacement, not a compliance certification product, not an SLA-backed commercial production platform, not an attack execution engine.

## Design-partner intent

A guided demo shows the reference experience. A controlled pilot places **customer-managed** identity, secrets, database, and runner under the customer’s infrastructure boundaries.
