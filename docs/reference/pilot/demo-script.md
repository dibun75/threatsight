# Five-minute guided demo script

Use the **live reference** at `https://threatsight.io` after owner sign-in. Do not claim unavailable features.

| # | Beat | Talking point | Show |
|---|------|---------------|------|
| 1 | Global change | A public signal appeared in the landscape | Radar / threat landscape |
| 2 | Evidence classes | Authoritative vs researcher-observed are separated | Cluster / CVE detail |
| 3 | Relevance | Map to technology and named business services | Service / correlation view |
| 4 | Uncertainty | Say what is known vs unknown — no customer-impact claim | Explicit labels |
| 5 | Verification | Recommend what to check next | Suggested verification |
| 6 | Accountable action | Human-approved readiness action | Action create/approve |
| 7 | Evidence seal | Manifest + signature (signer healthy) | Signing / verify |
| 8 | Response exercise | Practice coordination — not live IR | Response workspace |
| 9 | Deploy model | Customer runner outbound-only; secrets isolated | Architecture one-liner |
| 10 | Next step | Design-partner discovery — not auto-onboarding | Ask for scope questionnaire |

## Hard rules during the demo

- Label synthetic journeys as synthetic
- Never display tokens, keys, or `.env`
- Logout and Back should not resurrect the session
- If a screen looks like a customer claim, stop and correct language
